# Art bible

1. **Style** — Painted tabletop miniatures on a striped felt pitch: chunky primitive figurines with round heads and flat bases, clean chalk lines, a dark walnut game table around the field.
2. **Palette** (single source: `Assets/Scripts/Presentation/Palette.cs`)
   | Role | Hex |
   |---|---|
   | table (frame, background) | `#3B2A20` walnut · room `#211A15` |
   | pitch turf / stripe | `#3F8F4E` / `#4A9C59` |
   | chalk lines, ball | `#EEF0E6` |
   | Red primary / secondary | `#D94A3D` / `#F6E3D3` |
   | Blue primary / secondary | `#2F6BD6` / `#E3ECF8` |
   | Red keeper / Blue keeper | `#F08A24` / `#1FB5A8` |
   | skin | `#E7B98F` |
   | shadow | `#1F2A33` |
   | accent (selection, ball, UI highlight) | `#FFD23F` |
   | warning (blocked, invalid) | `#FF6B57` |
3. **Mood** — A warm lamp hanging over a game table late in the evening; cool slate bounce in the shadows; the pitch is the brightest thing in the room.
